## 1. Слои и приоритеты (утверждено Мастером, 2026-09-23)

Резолв значения ключа — строго в этом порядке:

```
1. env/compose (ЯВНО заданный)  — жёстко блокирует всё ниже
2. БД app_settings.value        — runtime-слой, меняется без рестарта
3. Дефолт из config.py          — база, значения сидинга = им
```

1. **Приоритет:** env/compose (явно заданный) > БД `app_settings` > дефолт `config.py`.
2. **Блокировка UI:** runtime-ключ, заданный в env/compose, ЖЁСТКО БЛОКИРУЕТ поле
   в интерфейсе: `read-only` + бейдж «Управляется через .env/compose».
   Разблокировка — только выпилить переменную из compose/.env и рестарт.
   Это блокировка, а не предупреждение.
3. **Детекция «задано в env»:** список оверрайдов = pydantic `model_fields_set`
   экземпляра `Settings` — точно отличает «задано в env» от «совпало с дефолтом».
   API возвращает `effective_source: "env" | "db" | "default"` на каждый ключ.
4. **Защита от опечаток:** env-ключ, которого нет в реестре, → WARN в лог + игнор
   (не падение процесса).
5. **Фундамент** (секреты, адреса/инфра) — env-only: в `app_settings` НЕ
   сидируется, через API настроек не отдаётся, в UI не отображается (раздел 3).

**Опасные настройки (`is_dangerous`):** запись значения И сброс к дефолту
(в т.ч. групповой «reset-all» по группе, содержащей опасные ключи) требуют
явного `confirm: true` в запросе; UI показывает бейдж «опасно» и модалку
подтверждения с человеческим текстом последствий.

**Рестарт-настройки (`requires_restart`):** значение в БД меняется, но
применяется при старте процесса; UI показывает бейдж «нужен рестарт».

## 6. Заметки для Соны (обязательные точки правки при переводе на runtime)

1. `api/web.py:125,193` — `Query(settings.search_default_threshold, ...)`
   вычисляется **при импорте модуля**: runtime-значение там заморожено.
   Перевод: `Query(None, ...)` + резолв внутри хендлера.
2. `api/web.py:212` — `le=settings.traverse_max_nodes` в FastAPI-валидации
   строится на этапе декоратора: перевести на `Query(None, ge=1)` + ручная
   проверка против `runtime.get("traverse_max_nodes")` (400 при превышении).
3. Детекция env-заданности — `Settings.model_fields_set` (§1.3); поле
   `effective_source` в GET-ответе — из него + наличия строки в БД.
4. Не менять дефолты в `config.py` параллельно с сидингом 027: сидинг Ф1
   копирует их бит-в-бит; рассинхрон = тихое расхождение «дефолт ≠ сидинг».

## 7. Регресс supersede/REWIRE (create_version-сценарий SQL-ом)

Полный сценарий в транзакции с ROLLBACK на живом дампе (правила REWIRE —
из §4 миграции 023, идентичны runtime `pg_repository.create_version`):

1. Выбрана asserted-гранула с резолвленным исходящим ребром (живая цель);
2. INSERT новой версии (version+1, supersedes, valid_from=now());
3. UPDATE старой: `status='superseded'`, `valid_to=now()`, `superseded_by`;
4. REWIRE: ребро переехало на наследника, `inherited_from` проставлен;

| Проверка | Результат |
|---|---|
| Боевой traverse от наследника (now()) | 1 ребро — REWIRE-перенос виден |
| Исторический traverse от старой версии (as_of = −1 день) | 1 ребро — проекция назад на inherited_from работает |
| Prune переехавшего ребра → боевой обход наследника | 0 рёбер (отсечено) |
| …при этом исторический обход старой версии | 1 ребро (as_of < pruned_at, видно) |
| ROLLBACK | 0 pruned, наследник удалён, 106 557 рёбер — следов не осталось |

Взаимодействие 026 × REWIRE-наследие корректно: pruned-рёбра не исчезают из
исторической проекции, боевой путь чист.

## Аномалии и наблюдения

1. **Хаб `0b99192a…` («Документация C++ cppreference») — 1532 исходящих ребра,
   все висячие** (target_id IS NULL, legacy-слой): обход от него пуст. Это не
   баг 026 — след старого линкера (46.6% корпуса — висячие target_name,
   известный факт ADR-019). Кейсы по висячим — Д6 тест-плана, иммунитет
   до резолва имён.
2. **Статистика планировщика по свежему индексу**: план 30-дневного окна
   оценил rows=178, фактически 19 751. Причина — индекс создан после
   последнего ANALYZE. На корректность планов не влияет (обе стратегии
   индексные), но **рекомендация: после применения 026 на проде выполнить
   `ANALYZE relations;`** (или дождаться autoanalyze после первой записи) —
   одно-секундная страховка от сюрпризов планировщика.
3. Все проверки на 106k строк выполняются на локальном стенде (NVMe, без
   конкуренции) — абсолютные тайминги на проде будут другими, но порядок
   (миллисекунды на DDL, десятки мс на decay-выборку) останется.

## 1. Видение: концепция «Deep Lumen»

**Selti — это глубина, в которой живёт память.** Интерфейс построен на одной метафоре и не выходит за её пределы:

> Память — не склад файлов, а тёмная толща воды, где каждая гранула — зерно биолюминесценции.
> Большая часть памяти спит во тьме; **свет появляется только там, куда направлено внимание.**

Из этой метафоры следуют все решения ниже. Тьма здесь — не «тёмная тема ради моды», а семантика: тёмный фон = несфокусированная память, свет = релевантность. Поисковый запрос — это луч фонаря: выдача «вспыхивает» с разной яркостью по score.

### 1.1 Три фирменных хода (signature moves)

1. **Свечение — это данные.** Glow используется не как декорация, а как кодировка величины: яркость/радиус свечения узла графа и карточки = importance; интенсивность score-бара = релевантность. Правило: *если элемент светится — за этим стоит число из API; если числа нет — элемент не светится.*
2. **Спектр слоёв памяти.** Каждый namespace имеет свой спектральный оттенок (см. палитру). Цвет namespace — единственный «цветной» элемент в нейтральном глубоком синем фоне, поэтому карта цветов интерфейса = карта слоёв памяти. Это делает «Граф» самодостаточным: легенда не нужна после первого экрана.
3. **Синапсы как первоклассный UI.** Связи гранул (relations, lineage) рисуются кривыми-«синапсами» (SVG), а не списками-табличками. Lineage версий — это тоже цепь: `v1 ──supersedes──▶ v2 ──▶ v3 (asserted)`. Связность — суть продукта, и она видна везде.

### 1.2 Характер

Спокойный, глубокий, точный. Никакой пестроты, никаких градиентных баннеров и glassmorphism-стекол: свет в глубине должен быть редким, чтобы оставаться сигналом. Анимации — медленные выдохи (200–400 ms, ease-out), никакого bounce. `prefers-reduced-motion` отключает всё, кроме opacity.

## 2. Токен-система

Источник правды — `tokens.css` (единый файл, импортируется раньше всех стилей). Хардкод цветов/размеров в компонентах запрещён. Именование — плоское, семантическое: `--sl-*` (selti).

### 2.1 Палитра (фон)

Глубокий сине-индиговый, с холодным подтоном. Ни один фон не чище `#0A0F1A` — «абсолютный чёрный» запрещён (на нём свечение выглядит грязью).

```css
:root {
  /* Surfaces — толща воды: чем выше слой, тем светлее */
  --sl-bg-abyss:   #060A12;  /* фон приложения */
  --sl-bg-deep:    #0A101B;  /* крупные зоны, canvas графа */
  --sl-bg-shell:   #0E1524;  /* панели, карточки */
  --sl-bg-raised:  #141D30;  /* ховер, popovers, input */
  --sl-bg-inset:   #080D16;  /* углубления: metadata-таблица, код */

  /* Borders */
  --sl-border:     #1B2540;  /* основной разделитель */
  --sl-border-strong: #273354; /* ховер границ, focus-рамки */

  /* Text */
  --sl-text:       #E8EEF7;  /* основной — контраст к abyss ≈ 15.9:1 (AAA) */
  --sl-text-2:     #9DACC6;  /* вторичный ≈ 7.6:1 (AAA) */
  --sl-text-3:     #63728F;  /* muted, mono-ID ≈ 4.6:1 (AA) */

  /* Accent — биолюминесценция (тёпло-бирюзовый, не «default tailwind cyan») */
  --sl-accent:        #5FE8C8;
  --sl-accent-dim:    rgba(95, 232, 200, 0.14); /* фоны accent-чипов */
  --sl-accent-glow:   0 0 24px rgba(95, 232, 200, 0.20);

  /* Semantic */
  --sl-danger:  #FF7A8A;
  --sl-warn:    #FFC15E;
  --sl-success: #5FE8C8;   /* совпадает с accent — одна «жизнь» в системе */
}
```

### 2.2 Спектр namespaces

Оттенки подобран попарно различимыми (в т.ч. для протанопии/дейтеранопии — проверено попарной разницей по luminance ≥ 0.15) и по контрасту к `--sl-bg-abyss` ≥ 4.5:1 для текста. На чипах оттенок используется точечно (точка 8px + текст нейтральный), заливка — всегда полупрозрачная (10–14%).

```css
:root {
  --sl-ns-user-facts:        #FF8E7A;  /* коралл      */
  --sl-ns-project-meta:      #A78BFF;  /* ирис        */
  --sl-ns-code-knowledge:    #4DC9FF;  /* лазурь      */
  --sl-ns-dialogue-insights: #86E3A0;  /* мята        */
  --sl-ns-infrastructure:    #FFC15E;  /* янтарь      */
  --sl-ns-default:           #8A97AC;  /* сланец      */
  --sl-ns-frozen:            #7DD3FC;  /* лёд (frozen-гранулы поверх namespace-цвета) */
  --sl-ns-superseded:        #4A5670;  /* затухший узел */
}
```

Новые namespaces из реестра получают оттенки из зарезервированной лестницы (12 hue-стопов, шаг 30°, saturation 70%, lightness 70%) — `namespaceToHue(uid)` детерминирован хешем uid, чтобы цвет был стабилен между сессиями.

### 2.3 Типографика

| Токен | Значение | Использование |
|---|---|---|
| `--sl-font-display` | `"Sora", sans-serif` | заголовки, логотип, крупные цифры |
| `--sl-font-body` | `"Inter", sans-serif` | текст, интерфейс |
| `--sl-font-mono` | `"JetBrains Mono", monospace` | id, score, метаданные, содержимое гранулы |

**Почему Sora:** геометричный, но с мягкими терминалами — «технологично без холода»; редкий в вебе, что работает на уникальность. **Inter** — рабочая лошадь для русского текста (полная кириллица, табличные цифры). **JetBrains Mono** обязателен: контент гранул и метаданные — суть технического текста, моно сразу отличает «данные» от «интерфейса».

Шкала (base 16, вертикальный ритм 8px):

```
--sl-text-xs: 12px / 16px   -- подписи, чипы
--sl-text-sm: 13px / 20px   -- метаданные
--sl-text-md: 15px / 24px   -- основной текст
--sl-text-lg: 18px / 28px   -- заголовки карточек
--sl-text-xl: 24px / 32px   -- заголовки экранов
--sl-text-2xl: 32px / 40px  -- hero-поиск (только там)
```

### 2.4 Спейсинг, радиусы, тени

```css
:root {
  /* Spacing — 4px base */
  --sl-s-1: 4px;  --sl-s-2: 8px;  --sl-s-3: 12px; --sl-s-4: 16px;
  --sl-s-5: 24px; --sl-s-6: 32px; --sl-s-7: 48px; --sl-s-8: 64px;

  /* Radii — мягкие, но не pill-овальные; pill только для чипов и бейджей */
  --sl-r-sm: 6px;   /* инпуты, мелкие кнопки */
  --sl-r-md: 10px;  /* карточки в списке */
  --sl-r-lg: 16px;  /* панели, модалки */
  --sl-r-xl: 24px;  /* hero-поиск, большие блоки */
  --sl-r-full: 999px;

  /* Elevation — тень «глубины», всегда синеватая, никогда — чёрная */
  --sl-shadow-1: 0 2px 8px  rgba(2, 6, 14, 0.50);
  --sl-shadow-2: 0 8px 32px rgba(2, 6, 14, 0.60);   /* панель карточки */
  --sl-shadow-3: 0 16px 64px rgba(2, 6, 14, 0.70);  /* модалка */

  /* Motion */
  --sl-ease: cubic-bezier(0.22, 1, 0.36, 1);  /* ease-out-quint */
  --sl-dur-fast: 150ms;  --sl-dur: 250ms;  --sl-dur-slow: 400ms;
}
```

### 2.5 Правила применения

- **60-30-10:** 60% — поверхности abyss/deep, 30% — текст и границы, 10% — акцент + спектр namespaces.
- Namespace-цвет разрешён в: точке чипа, spine-полосе карточки (3px), узле графа, подчёркивании вкладки. **Запрещён** в заливках кнопок и крупных плашках.
- Glow (`--sl-accent-glow` и hue-варианты) — только на: сфокусированном input, активном узле графа, текущей версии lineage, primary-кнопке.

## 3. Каркас приложения

- **Desktop-first, минимум 1280px.** Ниже 1280 — gracefully: правая панель карточки уезжает в overlay-модалку, чипы сворачиваются в «Ещё» (но приоритет — десктоп, это внутренняя тулза).
- **Shell:** верхняя навигация 56px (не сайдбар — продукт про контент, а не про разделы). Слева логотип-гроздь + `selti`; центр — табы `Поиск / Граф / Проекты / Статистика`; справа — health-кластер (живые цифры: гранулы, PG active, версия API).
- **Маршруты:** `/search`, `/memory/:id` (карточка = отдельный роут, открывается панелью поверх выдачи — deep-link сохраняется), `/graph`, `/projects`, `/stats`.
- **Иконки:** `bootstrap-icons` 1.11+ (единый штрих, есть все нужные: `search`, `diagram-3`, `collection`, `graph-up`, `link-45deg`, `clock-history`, `snow`, `pin-angle`).

## 4. Экран «Поиск» (`/search`)

### 4.1 Layout

```
┌──────────────────────────────────────────────────────────────────┐
│ topbar: selti | Поиск Граф Проекты Статистика | 14 588 · PG active│
├──────────────────────────────────────────────────────────────────┤
│              ┌────────────────────────────────────┐               │
│   hero:      │ ⌕  деплой фазы 2            [ / ]  │  ← до ввода   │
│              └────────────────────────────────────┘    центрирован │
│   [чипы фильтров: namespace ×5 · project · дата · статус]         │
│   ── вертикальный ритм 48px ──                                     │
│ ┌──────────────── результатов ────────────┐ ┌──── карточка ──────┐ │
│ │ Найдено 128 · 0.24 с                    │ │ (открытая гранула, │ │
│ │ [card: score | spine | excerpt]  ×N     │ │  sticky, 460px)    │ │
│ │ ...                                     │ │                    │ │
│ └─────────────────────────────────────────┘ └────────────────────┘ │
└──────────────────────────────────────────────────────────────────┘
```

**Состояние «лаконичный hero»:** до первого запроса поле поиска занимает вертикальный центр (google-стайл), под ним — 5 подсказок-примеров (real queries). После ввода hero сжимается до 72px и приклеивается к topbar (sticky) — выдача становится главным контентом. Сжатие анимируется 250ms ease-out.

### 4.2 Фильтры-чипы

- **Namespace-чипы:** точка спектра + название + счётчик. Мультивыбор (OR внутри namespace). Активный чип получает заливку 12% своего hue и glow.
- **Project:** dropdown с поиском по slug (реестр projects). Активный — чип с иконкой `collection`.
- **Дата:** presets (`24ч / 7д / 30д / всё`) — сегмент-контрол, не календарь (внутренняя тулза, кастом-диапазон избыточен).
- **Статус:** `asserted / superseded / retracted / frozen` — мультивыбор; `superseded` и `retracted` выключены по умолчанию (главный ответ интерфейса на «Google для памяти» — не показывать мёртвые версии, пока их не попросили).
- Активные фильтры — в URL query (`?q=&ns=&project=&status=`) — шеринг ссылки на выдачу обязателен.

### 4.3 Карточка результата

Структура: `[spine 3px, цвет namespace] [контент] [score-панель справа]`.

- **Score-панель** — фирменный компонент `ScoreGauge`: крупная моно-цифра score + спектральная полоса-разложение. Полоса делится на 3 сегмента (нормированные к 0..1 для визуализации, сырые значения в tooltip):
  - `rrf` — бирюза `--sl-accent`
  - `decay` — лазурь `--sl-ns-code-knowledge`
  - `importance` — ирис `--sl-ns-project-meta`
  
  Ховер на сегмент — tooltip: `rrf 0.0296 (dense+fts rank) · decay 0.94 (обновлено 12ч назад) · importance 5/5`. Формула `score = rrf × decay × importance` написана словами в легенде выдачи один раз — объяснение score это требование ТЗ, и мы выполняем его честно, а не только цифрой.
- **Excerpt:** до 3 строк с `line-clamp`; совпадения подсвечены `<mark>` (фон `--sl-accent-dim`, текст inherits).
- **Мета-строка:** namespace-чип · project · дата относительная («12 ч назад», моно) · первые 8 символов id (моно, `--sl-text-3`) · бейджи `frozen`/`v3`.
- Ховер карточки: фон → `--sl-bg-raised`, spine расширяется до 4px. Клик — карточка гранулы.

### 4.4 Состояния

| Состояние | Поведение |
|---|---|
| **Loading** | 4 скелетона карточек (shimmer по `--sl-bg-raised`, 1.4s); поле поиска не блокируется; debounce ввода 250ms |
| **Empty** | иконка `stars` + «Ничего не нашлось по „{q}“» + мягкие советы: убрать фильтры / искать по корню слова / проверить статус-фильтр |
| **Error** | иконка `wifi-off` + «Selti не отвечает» + кнопка «Повторить»; топбар-кластер краснеет |
| **Результаты** | счётчик `Найдено N гранул · X.XX с` (время — честно, моно); Infinity-scroll по 20, порог 400px |
| **Поиск при открытой карточке** | карточка закрывается, запрос уходит — фонарь снова главный |

## 5. Карточка гранулы (панель `/memory/:id`)

Правая sticky-панель 460px (`--sl-bg-shell`, radius-lg, shadow-2). Не модалка поверх всего: выдача видна слева — контекст поиска не теряется (однако роут отдельный: `/memory/:id` открывается по прямой ссылке как полноширинная страница).

### 5.1 Состав (сверху вниз)

1. **Шапка:** namespace-чип · статус-бейдж (`asserted` бирюза / `superseded` приглушён / `frozen` ❄ `--sl-ns-frozen`) · id полный (моно, копикнопка) · close.
2. **Content:** шрифт body, `--sl-text-md`; перенос строк сохраняется. Если гранула была заменена — под контентом деликатная плашка «Это устаревшая версия → актуальная v3» (линк).
3. **Score-декомпозиция** (если открыта из выдачи): тот же `ScoreGauge`, крупнее, с легендой.
4. **Metadata-таблица** (`--sl-bg-inset`, mono-значения): importance (5 точек-зёрен), user, project, entity_name, entity_type, namespace, created_at, updated_at, version, confidence.
5. **Lineage** — горизонтальная цепь версий: узлы-кружки с `v1..vN`, соединённые стрелками `supersedes`. Активная — бирюза с glow; superseded — приглушённые, кликабельные (переход к версии в этой же панели); над цепью — `clock-history` + «История версий · 3». Frozen-версия помечена снежинкой. Если версий > 5 — компакт-режим `v1 … v4 v5` с выпадашкой.
6. **Связи** — две секции:
   - **Исходящие** (стрелка вправо): `link_type` цветным моно-бейджем + название/обрывок целевой гранулы + score связи. Типы связей окрашиваются из лестницы hue (детерминированно по типу).
   - **Входящие** (стрелка влево): аналогично.
   - Клик по связи → карточка целевой гранулы (роут `/memory/:target`), в графе эта пара подсвечивается.
7. **Действия** (read-only + минимум админ): «Открыть в графе», «Копировать JSON», «Показать похожие» (`find_similar`, выдача в той же панели).

### 5.2 Состояния

- **Loading:** скелетон секций той же высоты (без CLS).
- **Error 404:** панель с «Гранула не найдена» + «Возможно, она удалена GC» + кнопка назад.
- **Relation hover:** в графе (если был на нём) соответствующее ребро вспыхивает — синхронизация поиск↔граф.

## 6. Экран «Граф» (`/graph`)

**Полноэкранный canvas** (`@react-sigma`, WebGL-рендер для 5К+ узлов — критерий приёмки плана). Единственный экран, где фон — чистый `--sl-bg-deep` без панелей.

### 6.1 Отображение

- **Узел = гранула:** цвет = namespace (спектр), радиус 4–14px = importance (log-шкала), glow = importance². Frozen — ледяной контур; superseded — затухший цвет 40% opacity; retracted — не рисуются (фильтр).
- **Ребро = relation:** толщина 1–3px = weight, цвет нейтральный `--sl-border-strong`; hover — цвет link_type.
- **Кластеры (Фаза 2):** легкие halo вокруг тематических кластеров (`assign_clusters`) — включаются тумблером «Слои» (по умолчанию off, чтобы глубина не превращалась в кашу).

### 6.2 Панели и управление

- **Левый флоат (280px):** поиск-центровка (выбор гранулы → камера анимируется к ней 400ms ease-out), чекбоксы namespaces (спектр-точки), слайдер «минимум importance», тумблер кластеров, счётчик видимых узлов «2 481 / 14 588».
- **Клик узла** → мини-карточка справа снизу (компактный вариант панели §5: контент 4 строки, namespace, 3 связи) + кнопка «Открыть полностью» (роут карточки).
- **Hover узла:** подсветка его рёбер 1-го уровня, остальные рёбра fade до 20%.
- **Контекст справа снизу:** легенда спектра (сворачиваемая), zoom-контролы.

### 6.3 Состояния

- **Loading:** пульсирующая надпись «Собираю созвездие…» + прогресс (граф грузится батчами по 1К узлов).
- **Empty (все фильтры off):** подсказка «Включите хотя бы один слой памяти».
- **Performance guard:** > 20К видимых узлов — предупреждение «Показаны первые 20 000 по importance».

## 7. Экран «Проекты» (`/projects`)

- **Переключатель вида: карточки (default) / таблица.** Карточки — Bento-сетка `repeat(auto-fill, minmax(360px, 1fr))`.
- **Карточка проекта:** slug (моно, крупно, display-шрифт) · name · description 2 строки · **стек-теги** (mono-чипы, нейтральные) · линки (github/web/репо — иконки `github`, `globe`, `folder-symlink`) · счётчики гранул по namespace (спектр-точки с числами — мини-легенда проекта) · кнопка «Открыть в графе».
- **Облачко-превью** (`/api/contexts/{slug}`): раскрывающаяся секция карточки — sections (`stack / decisions / insights / infra`) в виде 4 компакт-колонок, текст до 6 строк на секцию с «Показать всё» (роут `/projects/:slug`). Стиль облачка — `--sl-bg-inset`, mono-заголовки, никакого markdown-рендера сложнее списков.
- **Таблица:** slug · name · гранул всего · главный namespace (спектр-точка) · стек (топ-3 + `+N`) · обновлён.
- **Empty-state** для проекта без облачка: «Снапшот ещё собирается — будет готов после ближайшего цикла beat».

## 8. Экран «Статистика» (`/stats`)

Один экран-дашборд, но не generic: та же «глубина», метрики как светящиеся зерна.

- **Hero-ряд (4 метрики, крупные цифры display-шрифтом):** всего гранул · рост за 7д (sparkline 30д) · дедуп-рейшо (экономия, %) · hit-rate поиска (%, последние 24ч).
- **Ряд 2:** распределение по namespaces — горизонтальная спектральная стопка (одна полоса, сегменты = доля namespace, ширина по числу гранул; ховер — точные числа). Это фирменный компонент `SpectrumBar` — используется и на проектах.
- **Ряд 3:** рост базы (line-chart 90д, area с мягким бирюзовым свечением вниз), жизненный цикл (asserted/superseded/retracted — stacked area), очередь Celery (готовые/в работе, из `/api/stats`).
- **Мертвые данные:** отдельная карточка «Кандидаты на ревизию» (`stale_list`): count + топ-5 + кнопка «Перейти к поиску со статусом superseded».
- Все числа — из `/api/stats` + Prometheus-экспорт; при отсутствии данных секция показывает «—», а не ноль.

## 9. Доступность

- **Контраст:** весь текст ≥ AA на своих поверхностях (проверено: `--sl-text` 15.9:1, `--sl-text-2` 7.6:1, `--sl-text-3` 4.6:1 к `--sl-bg-abyss`). Namespace-оттенки как **текст** не используются (только точки/полосы/рамки) — семантика цвета всегда дублируется текстом названия.
- **Focus:** `:focus-visible` — 2px рамка `--sl-accent` + `--sl-accent-glow`, offset 2px. Порядок табуляции: поиск → чипы → результаты → панель карточки.
- **Клавиатура:** `/` — фокус в поиск; `Esc` — закрыть карточку; `↑/↓` — навигация по результатам; `Enter` — открыть. Подсказка `/` нарисована прямо в поле (kbd-чип).
- **ARIA:** чипы-фильтры = `button[aria-pressed]`; score-бар = `role="img" aria-label="Релевантность 0.87: rrf 0.94, decay 0.98, importance 0.95"`; панель карточки = `role="complementary" aria-label="Карточка гранулы"`; live-region объявляет «Найдено N гранул».
- **Motion:** `@media (prefers-reduced-motion: reduce)` — отключить shimmer, glow-пульсации, анимации камеры графа (переходы мгновенные opacity-only).
- **Граф:** полностью дублируется списком? Нет — но у каждой точки графа есть tooltip-альтернативный текст, а фильтры-чекбоксы клавиатурные; для скринридеров экран графа помечен `aria-label="Визуальный граф знаний, используйте экран Поиск"`.

## 10. Адаптивность

| Ширина | Поведение |
|---|---|
| ≥ 1440 | базовая сетка, панель карточки 480px |
| 1280–1439 | панель карточки 440px, bento-карточки проектов minmax 320px |
| < 1280 (деградация, не приоритет) | карточка гранулы → центральная модалка; граф — фуллскрин без левого флоата (фильтры в popover) |

Минимальная поддерживаемая ширина — 1024px; мобильная вёрстка вне скоупа Фазы 5 (внутренняя тулза).

## 11. Заметки по реализации

- Шрифты: Google Fonts (`Sora:wght@500;600;700`, `Inter:wght@400;500;600`, `JetBrains Mono:wght@400;500`) + `font-display: swap`; фолбэк-стек обязателен (офлайн-деплой за файрволом — шрифты кешировать локально при сборке).
- `ScoreGauge`, `SpectrumBar`, `NamespaceChip`, `GranuleCard`, `LineageChain`, `RelationList` — компоненты в `src/components/`, стили только на токенах.
- Цвета namespace — из API `/api/namespaces` (реестр), фронт лишь маппит uid → токен; новые namespace без токена получают hue из лестницы §2.2 на клиенте.
- Не тащить UI-библиотеку: компонентов мало, а уникальность языка важнее скорости Соны. Bootstrap-icons — только иконки.
